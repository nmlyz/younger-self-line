younger-self-line writes one line to a text file: the line its writer would send back to their younger self if one line were all they got. The line was picked from 38 candidates by pairwise judging against the brief — told straight to the younger self, naming one concrete thing from a life actually lived, with the turn landing on the last two words.

> Don't sell the blue bike — in ten years you'll walk past it in someone else's yard and still know every scratch.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run — verified by running it twice and comparing the outputs. The line is 112 characters, a single line and a single sentence. The program holds the line as one constant and checks it against the entry gate (length, single line, single sentence, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
